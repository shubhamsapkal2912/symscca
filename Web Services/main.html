SEM III / Web Services
📘 Subject Overview • 2413MJCT302

Web Services

Exhaustive coverage of Service-Oriented Architecture (SOA), Web Services operational model, XML-based wire protocols, SOAP messaging & error handling, WSDL service descriptors & lifecycle, UDDI registry data structures & inquiry/publishing APIs, and modern RESTful architectural style with JAX-RS and JSON frameworks.
