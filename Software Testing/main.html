SEM III / Software Testing
📘 Subject Overview • 2413MJET306B

Software Testing

Exhaustive engineering course covering Software Testing Life Cycle (STLC), IEEE 829 Test Plans, Defect Life Cycle, White-Box Testing (Logic coverage, Cyclomatic Complexity, Basis Path, Mutation, Data Flow), Black-Box Testing (Equivalence Class Partitioning, Boundary Value Analysis, Cause-Effect graphing, Decision Tables), System & Acceptance Testing (Alpha/Beta, Performance, Regression, Usability, Internationalization), and Test Management & Automation Metrics (DRE, Defect Density).
