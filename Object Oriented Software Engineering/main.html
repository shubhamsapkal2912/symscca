SEM III / Object Oriented Software Engineering
📘 Subject Overview • 2413MJCT303

Object Oriented Software Engineering

Comprehensive engineering course covering Structured System Analysis & Design (SSAD) vs Object-Oriented Analysis & Design (OOAD), SDLC Process Models (Waterfall, Spiral, Prototyping, RAD), Requirements Engineering & SRS (IEEE 830), Unified Modeling Language (UML) structural and behavioral modeling (Class, Object, Use Case, Sequence, Activity, Statechart, Component, Deployment), and the Unified Process (UP) lifecycle.

2 Credits
2 Hrs/Week Teaching Scheme
5 Syllabus Units
